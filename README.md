# bubb4rd/tap

Homebrew casks for [bubb4rd](https://github.com/bubb4rd)'s apps.

```sh
brew install --cask bubb4rd/tap/glassusage
```

| Cask | App |
| --- | --- |
| `glassusage` | [GlassUsage](https://github.com/bubb4rd/GlassUsage): Claude and Codex plan limits and token spend in the macOS menu bar |

Casks are updated automatically when a new release is published.
